Aplicación Full Stack desarrollada para gestionar productos, usuarios, órdenes, pagos y promociones.

**Stack**

`Angular` · `Spring Boot` · `MySQL` · `JWT` · `Spring Security` · `JUnit`

* 🔐 Autenticación y autorización con JWT
* 👥 Gestión de usuarios y roles
* 🍕 Gestión de productos

* 💳 Gestión de pagos
